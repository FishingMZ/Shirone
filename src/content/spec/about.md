# 关于 Shirone

欢迎来到 **Shirone**（白音）的演示站点——一个富有表现力、受动漫启发的博客主题，基于 **Material 3 Expressive (M3E)** 设计系统构建。

::github{repo="LyraVoid/Shirone"}

## ✦ 设计与理念

Shirone 旨在将富有表现力的动漫美学的温暖与现代 Web 工程的严谨性相结合：

- **动态色彩魔法**：完整的动态 HCT 调色板生成，无缝响应明暗模式和用户偏好，且零布局偏移。
- **无缝外壳导航**：由 Swup 驱动的持久化应用外壳，实现连续音乐播放、平滑页面过渡和状态保留。
- **丰富的故事魔典**：使用 Markdown 和 MDX 创作，支持 KaTeX 数学公式、Mermaid 图表、交互式提示块、富有表现力的代码块和自适应图片画廊。
- **零额外负担**：可选集成（评论、分析、音乐组件）按需动态加载——禁用时零 DOM 占用和零打包开销。

## ✦ 技术栈

- **框架**：[Astro 7](https://astro.build/) 和 [Svelte 5](https://svelte.dev/)（Runes 驱动的岛屿架构）
- **样式**：[Tailwind CSS 4](https://tailwindcss.com/) 和 [Stylus](https://stylus-lang.com/)
- **设计标准**：[Material 3 Expressive](https://m3.material.io/)
- **排版**：Outfit 和 Yozai（悠哉圆体），支持构建时自动子集化
- **搜索引擎**：[Pagefind](https://pagefind.app/) 离线全文搜索
